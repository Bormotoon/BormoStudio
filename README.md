# BormoStudio

Локальное десктопное приложение для полного цикла обработки видеозаписек: сканирование материала с камер и рекордеров, транскрипция, синхронизация звука, черновой монтаж, вычитка текста, статья и короткие рилсы — с экспортом проектов для Final Cut Pro (FCPXML) и Adobe Premiere (XMEML).

Всё работает локально: Whisper, pyannote и llama.cpp выполняются на машине пользователя, без облачных API.

> **Статус (2026-10-10):** активная разработка. Локально реализованы этапы всех фаз 1–5 и основа фазы 6;
> ни одна фаза ещё не прошла приёмку на реальных моделях, реальной записи и в Final Cut/Premiere.
> Подробности — [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md).
>
> Установка: `pip install -e ".[dev,whisper]"`. CLI: `bstudio scan|plan|run|review|verify|batch|channel|fetch|material|modules|models|compute|doctor`;
> GUI: `bstudio-gui`. Внутренний пакет `studio` и старые команды пока сохранены для совместимости.

## Происхождение проекта

BormoStudio объединяет два действующих проекта:

| | [WhisperSync](https://github.com/Bormotoon/WhisperSync) | [Podcast Reels Forge](https://github.com/Bormotoon/Podcast-Reels-Forge) |
|---|---|---|
| Назначение | синхронизация звука рекордера с видео, коррекция дрейфа часов, FCPXML | рилсы, вычитка и статья из длинного эпизода |
| Интерфейс | PyQt6 | CLI + веб-редактор субтитров |
| Лицензия | PolyForm Noncommercial 1.0.0 | MIT |

История обоих проектов импортирована в этот репозиторий через `git subtree`; замороженные снимки исходников лежат в `legacy/`. Исходные репозитории не изменяются (решение владельца).

## Что умеет (целевая функциональность)

1. **Папка на входе** — файлы камер и рекордеров вперемешку, или ссылка на YouTube.
2. **Синхронизация** в четырёх режимах: авто, «звук камеры», простая (сдвиг), сложная (коррекция дрейфа).
3. **Опциональные этапы:** черновой монтаж (паузы, дубли, слова-паразиты), спикеры, рилсы, вычитка и статья — любой этап можно выключить, пропуск не ломает остальные.
4. **Экспорт:** `.fcpxml` для Final Cut, `.xml` (XMEML) для Premiere, синхронизированный звук, транскрипты, мастер-WAV.

Принципы: исходники неприкосновенны; всё локально; ничего не пересчитывается зря (fingerprint + manifest у каждого этапа); логика ядра не зависит от интерфейса.

## Технологии

Python 3.12 (CI: 3.10–3.13) · PyQt6 · faster-whisper (CTranslate2) · pyannote.audio (опц.) · llama.cpp · torch/OpenCV (опц., для рилсов и мультикамеры) · ffmpeg (NVENC).

Тяжёлые зависимости выносятся в опциональные модули-окружения, управляемые встроенным менеджером — базовая установка остаётся лёгкой.

## Разработка

```bash
pip install -e ".[dev,whisper]"
QT_QPA_PLATFORM=offscreen python -m pytest -q   # 410 passed, 2 skipped (Python 3.10, 2026-10-10)
ruff check studio tests
mypy studio tools                                # обязательно для CI (Python 3.12)
python tools/make_fixtures.py                    # синтетический проект для ручного прогона
pyinstaller packaging/pyinstaller/studio.spec    # локальный Linux-бинарник
```

Порядок знакомства: раздел 0 плана (аудит), разделы 4–5 (архитектура и этапы),
затем текущий срез в `docs/IMPLEMENTATION_STATUS.md`. Вопросы — в
[Issues](https://github.com/Bormotoon/BormoStudio/issues).
